    G4AR Unlock / Radio Lab
    Owned hardware research warning

    This lab is for Arcadyan TMO-G4AR gateways the user owns, such as secondhand eBay or Amazon units. Firmware override, LTE/NSA radio experiments, modem commands, and external antenna mods can brick hardware, void warranty, break service terms, or create RF compliance problems.

    What is this URL?

    Docker auto-fills its own built-in adapter URL. That removes the setup guesswork for health checks and lab defaults. Real firmware backup, tower lock, cell scan, or radio-profile commands still need trusted hardware bridge tooling attached to the modem side of your lab setup.

    http://127.0.0.1:8000 http://router.local:8080 http://192.168.1.2:8765 GET /health POST /g4ar/firmware/backup
